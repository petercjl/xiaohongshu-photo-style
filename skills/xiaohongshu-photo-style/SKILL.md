# 小红书图片风格

输入一张本地图片，可指定标题、风格、尺寸和交付目录。默认保留画布与构图，输出 PNG。用户需要继续编辑时，同时交付保留原图、调色层、文字和文字效果的 PSD。原文件只读。先检查输入和目标路径，使用新的输出名或目录。

在已托管安装中，从 Skill 目录下的 `.runtime` 调用配套管理入口的 `update check --json`，使用默认节流。发现新版时提示用户。

## 执行能力

视觉判断、文案、调色参数和排版由本 Skill 决定。通过宿主按准确名称解析并完整读取 `photocraft-own`，按该 Skill 的 N1–N5 执行与核验。它是必需依赖，使用其当前原生 CLI 合约。验证能读图、添加曲线或色彩调整层、创建中文文字与图层效果、保存 PSD 并导出 PNG。找不到 Skill 时报告 `DEPENDENCY_MISSING`，已安装版本缺少必要操作时报告具体能力缺口。编辑完成后回到本 Skill 的验收。所有操作在本地文件上完成。

## 1. 调色

先看原图，识别主体、照明来源、色偏、亮暗层次和应保护的颜色。根据图像选择方向：

- 暖光室内照保留暖光来源，用曲线轻提主体暗部和中间调，必要时轻收高光。中间调过黄时用色彩平衡小幅修正。
- 日光生活照优先校正偏色，再按需抬中间调和控制高光，保留肤色与商品本色。
- 背景颜色抢眼时，优先减弱相关色域，保持主体辨识度。画面原有层次适合时只做轻量调整。

用可编辑调整层实现。记录选择理由和实际参数。调色预览须保有主体纹理，检查灯源、高光、暗部和商品颜色，再以调色后的预览选择花字颜色和位置。

## 2. 贴花字

进入本步时打开[花字图文模板卡](references/lettering-cards.md)，按调色后画面的留白和笔记气质筛选，实际查看候选参考图，再读取对应文字规则。参考图用于判断视觉效果，文字规则用于还原字体、层级、装饰和比例。选定后按本图适配，记录模板编号。若参考图无法查看，说明匹配仅基于文字。

用户给标题时保留原文，可按语义换行。只给图片时，从看得见的主体和场景写短标题。价格、功效、材质和个人使用经历需要用户提供依据。

先找留白，再定字。保护主体、脸和关键细节，预留边距，避开反差突变和高亮区域。优先一到两行，靠字号和字重突出一个关键词，颜色从画面取呼应色并确保对比。家居生活照可用暖白或浅色字、同色系深边和轻阴影。背景纹理强时先换位置，再考虑加强描边或加一块小底色。留白紧张时优先缩短自拟标题。用本机实际可用且覆盖中文字形的字体，保留文字和效果的可编辑性。

## 同一组图片

先通览整组，识别封面、叙事和细节页，选一张图文模板卡作为整组基准。固定字族、主辅色、轮廓或底贴形状、装饰语汇及字号层级。模板库用于选整组风格。内页沿用基准模板的简化形式，通过文字、落位、方向和大小适应留白。封面用主标题，内页用较小的同款字贴。细节页可加同色短箭头。留白紧张时优先缩短文案、缩小标签或让该页留白。方向变化较大时仍保留字族、配色和边缘关系。

先检查单张，再按发布顺序把全组缩到约 320 px 宽并排检查。封面、内页和细节页应有清楚的强弱层级。若某张因字形、颜色或装饰显得像另一套，调回基准样式后重新检查。整组调色保持接近，同时保留各张原有光线和商品颜色。

## 验收与交付

- 用调色后的预览核对色调，用成图核对文案、主体避让、边距、描边和缺字。在约 320 px 宽预览中检查能否一眼读出标题。
- 检查导出格式和尺寸。要求 PSD 时重新打开并核对底图、调整层、文本内容、字体和图层效果，再检查由该 PSD 导出的 PNG。
- 交付已验证的文件路径与两步实际处理摘要。若文字验收失败，保留已验收的调色，修改文字与效果后重新导出。若调色变化，重新检查文字对比。区分已验证结果和未通过项。
