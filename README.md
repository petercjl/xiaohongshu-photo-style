# 小红书图片风格

使用本地 PhotoCraft 给照片调色、贴花字。单图可从 12 张图文模板卡中选样，同组图片共用字族、颜色和纸贴样式。默认输出 PNG，需要继续编辑时可附 PSD。

需要当前 Agent 能查看图片、访问本地文件和执行命令。图片编辑需要可用的 PhotoCraft Own 运行时及其配套 Skill。图片在本地处理。

- 安装。把「帮我安装 @petercjl/xiaohongshu-photo-style。」发给当前使用的 Agent。见 [安装说明](INSTALL.md)。
- 更新。把「帮我更新 @petercjl/xiaohongshu-photo-style。」发给当前使用的 Agent。见 [更新说明](UPDATE.md)。
- 使用。附一张图或一组图，发送「用 xiaohongshu-photo-style 做成小红书风格，整组保持一致。」
